# 伴宠有方 · 智能化养宠管理平台

> 面向猫狗及异宠饲养家庭的一站式养宠管理 Web 应用，整合宠物档案、每日喂食、免疫驱虫提醒、养宠记账与专业养护百科。

## 一、项目介绍

「伴宠有方」是一款基于 Vue 3 的前端单页应用（SPA），围绕宠物从幼年到老年的完整生命周期，
帮助主人用数据化的方式记录成长、规避遗忘、科学喂养。

核心能力：

- **账号注册 / 登录**：账号唯一性校验、密码一致性校验，登录状态本地持久化。
- **宠物档案**：多宠基础资料管理，支持头像上传。
- **每日喂食**：记录每餐时间、份量与品类，汇总进食规律并给出喂养提示。
- **免疫日历**：录入疫苗 / 驱虫计划，自动计算下次接种日，临近到期主动提醒。
- **日常账本**：养宠开销记录、分类汇总与消费分析。
- **养护百科**：多分类检索、关键词搜索、热门标签筛选与分页浏览，支持百度直达检索。

## 二、技术架构

| 层级 | 技术 |
| --- | --- |
| 前端框架 | Vue 3（Composition API / `<script setup>`） |
| 构建工具 | Vite |
| 路由 | Vue Router（SPA 无刷新切换） |
| UI 组件 | Element Plus |
| 数据存储 | 浏览器 localStorage（本地持久化） |
| 样式 | 原生 CSS，手帐 / 便签风格 |

采用轻量化本地架构：数据持久化保存、开箱即用，无需额外部署服务器；
系统内置自动到期提醒、喂食与开销统计分析、分类检索等智能化能力，登录与业务数据均保存在本地，离线演示流畅稳定。

## 四、安装与运行指南

### 环境要求

- Node.js ≥ 16（推荐 18+）
- npm ≥ 8

### 步骤

```bash
# 1. 安装依赖
npm install

# 2. 本地开发运行（默认 http://localhost:5173）
npm run dev

# 3. 打包生产版本
npm run build

# 4. 预览打包结果
npm run preview
```

依赖全部记录在 `package.json`，执行 `npm install` 即可自动安装，无需手动逐个安装。

## 五、环境变量配置

项目当前不强制配置环境变量。如后续接入第三方服务（如大模型接口），
请按以下规则管理，**严禁把真实密钥提交到公开仓库**：

1. 复制模板文件，生成本地文件：

   ```bash
   cp .env.example .env
   ```

2. 在 `.env` 中填写真实值；`.env` 已在 `.gitignore` 中排除，不会被提交。
3. 仓库中只保留 `.env.example`，里面全部是占位符。

变量命名需以 `VITE_` 开头，前端才能通过 `import.meta.env` 读取。

## 六、使用说明

1. 打开应用后先注册账号（同名账号会被拦截），再登录。
2. 在「宠物档案」创建宠物并上传头像。
3. 日常在「每日喂食」「免疫日历」「日常账本」记录数据。
4. 在「养护百科」按分类浏览或搜索养宠知识。
